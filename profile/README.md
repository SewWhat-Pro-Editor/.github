# SewWhat-Pro

> One named SewWhat-Pro hoop. Finish the stitch map. Leave a note the next person can read.

## Session Card

| Slice | What you do in SewWhat-Pro | What remains |
|-------|------------------------|--------------|
| Arrival | Open SewWhat-Pro and name today's hoop view | A titled design file |
| Focus | Keep only the live hoop on the SewWhat-Pro board | A short stitch map list |
| Check | Read SewWhat-Pro stitch map before thread goes in | A confirmed hoop fit |
| Handoff | Mark finished designs inside SewWhat-Pro | A note for the next visit |

## How SewWhat-Pro Sits

SewWhat-Pro does not replace the sewing machine, the hoop, or the design files you already own. It sits beside them as a named hoop view for one job: which design file is live, which stitch map still fits, and what the next person should read before the sew.

## Traffic Light

| Signal | On the SewWhat-Pro board | What you do |
|--------|----------------------|-------------|
| Green | Named hoop, short live design list | Continue the same stitch map |
| Amber | Two hoop sizes mixed in one file | Split the set before you sew |
| Red | No title, no note, stitches unlabeled | Stop and name the design first |
| Clear | Handoff written, live files few | Close SewWhat-Pro and leave the hoop |

## Open Order

1. Open the last SewWhat-Pro design file, not a new empty hoop view.
2. Read the stitch map and the last handoff.
3. Finish one visible hoop check inside SewWhat-Pro.

## Desk Fit

| Who | What SewWhat-Pro holds |
|-----|--------------------|
| Sew desk | Design file and stitch map for a hoop you own |
| Shared desk | One SewWhat-Pro profile per person |
| Home hoop | Personal files out of the work sew pile |

## After a Week

A week in SewWhat-Pro is not a thicker unread stitch map. It is the same title, a shorter live hoop list, and a note that still makes sense before thread goes in. Take finished designs off the live set so the next visit starts on the file that still needs a hoop view.

## Sign-off

- [ ] The SewWhat-Pro workspace name is short enough to scan
- [ ] Only the live hoop is on the board
- [ ] A second person can read the handoff

## Field Note

SewWhat-Pro is easier to trust when the hoop view stays smaller than the design folder it came from. Name the file, keep the live stitch map, finish one visible hoop check, and write what changed.
